# HDRI

`apartment.js` is the "apartment" HDR environment map from [Poly Haven](https://polyhaven.com/hdris)
(CC0 1.0, public domain), resized to 512 × 256 and DWAB-compressed by the
[pmndrs/assets](https://github.com/pmndrs/assets) project (also CC0). It's stored as base64 data in a small
JS module so it loads from any static host, and lights the inside of the house during the walk-through
(soft bounce light and reflections in glass, metal and counters).
