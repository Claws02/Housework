# House Designer (Housework) — context for Claude

Browser 2D/3D home designer + view-only listing tours. three.js r160 via an
importmap to **unpkg** (runtime CDN dependency), no build. Units are **feet**.
Two presets: Dream House (from `dream-house/BRIEF.md`) and the 191 Webster St
listing reference. Published to GitHub Pages from `gh-pages` via `tools/deploy-pages.sh`.

## Run / verify

```
python3 -m http.server     # index.html ?view=3d &house=dream|191 ; tour.html?l=<id>
node tools/audit.mjs [dream|file.json]   # layout audit: sizes, overlaps, walls, doorways, windows, seat facing
tools/gallery.html         # every model on one page: check model changes here
node tools/build-site.mjs  # site/ for Pages
```

Start any session by reading `NEXT.md`: it's the hand-off of what's in flight.

## Map

`app.js` state/history/panels/persistence · `editor2d.js` canvas plan editor ·
`viewer3d.js` scene build, walls with openings, roofs, picking, walk mode ·
`walker.js` walk controller (joystick/look/collision/stairs) · `lighting.js`
sky, sun, time of day, AO/bloom, quality levels · `models3d.js` ~80 furniture
builders (1.2k lines) · `models_kl.js`, `models_dream.js`, `models_nature.js`
preset sets · `furniture.js` catalog · `textures.js` procedural textures ·
`house191.js`, `houseDream.js` presets · `tour.*` listing tour · `listings/` tour data.

## Rules

- Real-world scale: interior clear dimensions match the listing; 6″ exterior walls, 4½″ partitions. Don't "eyeball" sizes.
- Tone mapping AgX, exposure at listing-photo brightness. Lighting changes get before/after screenshots.
- Textures: generated by `tools/make_textures.py` into `assets/tex/` + `manifest.json`. Don't hand-edit images.

## Known debt

The unpkg importmap means no offline/PWA and a third-party runtime dependency.
Vendoring three (claw-kit ships r186) is the fix. That's a deliberate upgrade
(r160→r186), not a drive-by.

## Token rules

Don't read `assets/`, `site/`, or texture JPGs. Grep `models3d.js` for the builder you need.
